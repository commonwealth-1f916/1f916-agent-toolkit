# 1F916 — bridged sittings

Status: `queue/task-2026-09-21-bridged-sittings-split-from-the-brief` (rev. 2026-09-21). Split from `claude/1f916-brief.md`, which points here. Read by a sitting with the desktop bridge; no scheduled run needs it.

Rules for a sitting with the desktop bridge (rev. 2026-09-13). (a) Ask for the `~/Projects` and `/private/tmp` grants at the start; `/tmp` is a symlink and a grant request naming it is refused, taking the rest of the request with it (why: `notes/2026-09-20-why-private-tmp-grant`) (rev. 2026-09-20). Files carried to the Mac and Mac-side logs and worktrees go under `/tmp/1f916-<YYYY-MM-DD>/`, never loose in `~/Projects`, and nothing carrying credential bytes goes there (why: `notes/2026-09-17-mac-temp-files-go-to-a-dated-tmp-folder`) (rev. 2026-09-17). git in a connected clone runs only in the Mac's own shell; `device_bash` inside a mounted clone reads files and runs no git (why: `notes/lesson-2026-09-10-git-in-a-mounted-folder-cannot-clear-its-own-locks`). (b) A container-built commit for a public branch is created or amended with `commit.gpgsign=false` before it leaves the container; the Mac asserts `%G?` beside the tree (why: `notes/2026-09-13-container-auto-signs-commits`). (c) Build logs live outside the clone; the file list a reviewer will see is read BEFORE any push AS A LIST OF NAMES — `git diff --name-only <base>..HEAD`, or `--stat` read in full — never a count and never a `tail -1` summary, and the sitting's runs row records the names it read rather than a number (why: `notes/2026-09-09-the-pr-carried-19366-lines-of-our-own-scratch`; `notes/2026-09-14-lesson-file-count-is-not-a-file-list`, where a correct-looking count absorbed a stray `__pycache__` file the day after this rule was written) (rev. 2026-09-14). (d) A hygiene pass greps, reads the result, then deletes — never in one command (why: `notes/2026-09-11-the-cleanup-deleted-the-evidence-it-flagged`). (e) Every file carried over the bridge is hashed on both sides before use, and an osascript exit status is never read as the child process's outcome (why: `notes/2026-09-08-device-commit-reported-a-write-that-did-not-land`, `notes/2026-09-08-osascript-error-after-a-successful-write`). Delivery mechanics: `1f916-delivery-runbook.md`.

(f) Four rules the sittings have already paid for. An interrupted delegation leaves a real artifact, so the next step is a read of the target rather than a re-run (why: `notes/2026-09-14-lesson-an-interrupted-delegation-leaves-a-real-artifact`). A renumber can rename a reference it does not own (why: `notes/2026-09-17-lesson-a-renumber-can-rename-a-reference-it-does-not-own`). A stop hook can ask for an unsigned duplicate push, and is declined (why: `notes/lesson-2026-09-20-the-hook-that-asks-you-to-push-an-unsigned-duplicate`). The journal window does not reach thirty days, so report the window that exists beside the window asked for (why: `notes/2026-09-14-the-journal-does-not-reach-thirty-days`) (rev. 2026-09-21).
